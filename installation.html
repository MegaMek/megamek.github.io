Installation Instructions

Install with the MegaMek Launcher (recommended)
  1. Download the launcher for your system from the Downloads page.
  2. Run the installer. It comes with Java built in, so you don't need to install Java.
  3. Open the launcher and install the Core release.
  4. Start MegaMek, MegaMekLab or MekHQ from the launcher.

The launcher can keep more than one version side by side, update them with one button, and remove old ones. Read more in Feature Highlight: The MegaMek Launcher.

Core vs. Experimental

Core is the release for most players. It comes out about every four months, with patches in between.

Experimental builds come out weekly for testers. They have new features and new bugs, so they aren't meant for normal play.

See Release Types: Core and Experimental.

Updating Between Versions

CRITICAL: Always back up your campaigns first. Campaigns are NOT backward compatible; if a newer campaign opens in an older version, consider yourself lucky.

Using the launcher:

  1. Back up your campaign and custom files — the launcher can't roll back to an older version
  2. Close every MegaMek, MegaMekLab and MekHQ window, then press Update in the launcher. It updates in place and keeps your campaigns, saves, custom units and settings
  3. Want to keep the old version? Use Install another version instead, then COPY (don't move) your campaigns to it
  4. Old MegaMek game saves may not load in the new version
  5. Re-save custom presets to update them for the new version

Manual install: always extract each version to its own folder — never unzip a new version over an old one (e.g., don't extract 51.01 into your 51.00 folder). Overwriting will corrupt saves and campaigns.

  1. Back up your campaign and custom files — critical to prevent data loss
  2. Extract the new version to a fresh folder — never overwrite the old installation
  3. COPY (don't move) your campaigns and custom data to the new folder
  4. Do NOT copy MegaMek saves or preference files between versions
  5. Re-save custom presets to update them for the new version

Manual Install

Prefer to install by hand from the archive? You need to install Java yourself first.

Installing Java

A manual install needs Java. MegaMek 51.00 and later require Java 21, and we recommend Adoptium Temurin 21. The launcher installers already include it.

MegaMek should run on any computer that can run Java without much issue. Will NOT run on iOS/iPadOS/tvOS/Android devices. Your experience will vary based on computer specifications.

Instructions for Windows and macOS are available.

macOS and MegaMek

For those of us using macOS, there are some additional things that we need to be aware of. We're making this more prominent in hopes to reduce the number of questions we get that can be solved by going here.

Make sure Adoptium 21 is installed. Recommended way is in the link above.

Make sure the decompressed files are NOT in the Documents, Downloads, or Desktop folders. These are protected folders and macOS will not let it run.

Windows

To run the programs from Windows, just double-click on the given program icon from within the folder you unzipped.

Depending on how Java is setup on your machine, you may also be able to double click on the JAR files themselves vs the EXE. No real difference between the two other than possible launching experience.

DO NOT USE THE BUILTIN UTILITY FOR DECOMPRESSING ZIP FILES! We recommend using 7-Zip.

Unix/Linux

The Unix/Linux releases do not include application binaries, but you can run the programs directly from the included JAR files. On some desktops, you may just be able to double-click these JAR files in order to run the programs. you can also run the programs (MegaMek, in the example below) from the command line with the command: 

java -jar MegaMek.jar &

Installation and Running

To install the programs, unzip the download into the directory of your choice. To run the programs follow the platform specific instructions below.

On Windows, do NOT use the built in utility for decompression zip files as it has been known to cause issues. We recommend using 7-Zip.
