Roles asked vs roles delivered

When a slot asks for a role, how often the RAT Generator's own role rules accept the unit it gets. Recon, cavalry and anti-aircraft also take untagged units that fit (fast 'Meks, hovercraft, flak weapons), and omni reads the unit's omni flag, so the tagged share is lower. Roles a unit type cannot take, such as omni on a Nova's battle armor, are left out.

Weight asked vs weight delivered

Rows: the weight class the slot asked for. Columns: what it got. The Force Generator picks a lance's units from the weight classes the lance asked for, then hands them out to its slots, so a slot can get a neighbour's weight while the lance stays in its classes.

What availability changes do

For the most-picked chassis, the overnight run moved this faction's chassis code down 2, up 2, and to 0, then built the same forces again with the same dice. A move counts as real (●) only when it is bigger than chance and bigger than the control run, which rebuilt the forces with different dice and no edit.

How this was made

A study runs MegaMek's Force Generator (the steps of Ruleset.processRoot) hundreds of times with seeded dice. Before units are picked it records what each slot of the force tree asks for: unit type, formation, roles and weight class. Afterwards it records the unit picked. Sensitivity runs change one availability code in memory, as the RAT Editor would, and repeat the same seeds.
