      Unit

      Each cell is an availability code from the era files, the same grid as the RAT Editor. Type a new value (for example 6, 7+, 5-, 4:3055 or !A:6!B:4) and press Enter; clear a cell to remove the code. A code of 0 takes the unit out of this faction's own table; salvage from other factions can still bring it in. A cleared cell falls back to the parent faction's code (for example IS), so clearing alone may change nothing. Hover over a cell to see the whole code and what it gives at each equipment rating. Right-click a cell for an editor with − and + buttons and the unit's chance before and after. The table above updates at once. Edits stay in this browser tab only.

      How these numbers are made

      Where the data comes from

      The same files MegaMek loads:

      • availability codes from the era files
      • unit stats (weight class, motive, roles)
      • faction settings (ratings, salvage, weight mix)

      How a roll works

      1. Salvage first. If the salvage chance hits, the unit comes from the salvage faction's table five years earlier.
      2. Otherwise, by weight. A unit's chance is its weight divided by the total weight of the faction's own units.
      3. Codes set weight. Weight is 2code / 2, so a code 2 higher doubles it. A code of 0 or less leaves the unit out.

      How it is checked

      Your browser runs a copy of the RAT Generator's table-building steps.

      Every published build is compared with MegaMek itself on thousands of random tables. They agree to within MegaMek's own rounding.
