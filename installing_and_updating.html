Core vs. Experimental

Core is the release for most players. It comes out about every four months. Fixes can now ship as patches in between, so you don't wait months for a bug fix.

Experimental builds come out weekly for our testers. They have the newest features and the newest bugs, so they aren't meant for normal play. If you run one, use the Report Bug button. Install them through the launcher, or get the archives from the GitHub releases pages for MegaMek, MegaMekLab and MekHQ.

These replace the old Nightly, Development and Milestone releases. See Release Types: Core and Experimental.

Updating Between Versions

CRITICAL: Always back up your campaigns first. Campaigns are NOT backward compatible.

Using the launcher (Recommended)
  1. Back up your campaign and custom files — the launcher can't roll back to an older version
  2. Close every MegaMek, MegaMekLab and MekHQ window, then press Update in the launcher. It updates in place and keeps your campaigns, saves, custom units and settings
  3. Want to keep the old version? Use Install another version instead
  4. Old MegaMek game saves may not load in the new version
Manual install (Not recommended, use the launcher)

Always extract each version to its own folder — never unpack a new version over an old one (e.g., don't unpack 51.01 into your 51.00 folder). Overwriting will corrupt saves and campaigns.

  1. Back up your campaign and custom files — critical to prevent data loss
  2. Extract the new version to a fresh folder — never overwrite the old installation
  3. COPY (don't move) your campaigns and custom data to the new folder
  4. Do NOT copy MegaMek saves or preference files between versions
  5. Re-save custom presets to update them for the new version

Manual Install (Not recommended, use the launcher)

Only for players NOT using the MegaMek Launcher. If you installed the launcher, stop here: it already installs the programs, includes Java, and handles updates. Follow these steps only if you want to install by hand from the .tar.gz archive.

3. Unpack the archive

The download is a .tar.gz archive that works on Windows, macOS and Linux. Unpack each version into its own new folder. Never unpack a new version over an old one.

Windows: do NOT use the built-in Windows extractor. It struggles with the thousands of files in the archive and can fail or corrupt them. We recommend 7-Zip.

macOS: do NOT unpack into a protected folder: Documents, Downloads or Desktop. macOS will not let the programs run there. A Games folder in your home folder works well.

Linux: do NOT ever unpack into the root folder (/) or as root with sudo. Unpack into a folder in your home folder, such as ~/Games.

All systems: do NOT unpack into a cloud folder (Dropbox, OneDrive, Google Drive or iCloud). The sync can move or remove files while the program runs, and strange things happen.

4. Run the programs

Windows

Double-click MekHQ.exe, MegaMek.exe or MegaMekLab.exe in the folder you unpacked.

macOS

Open Terminal in the folder you unpacked and run the program's script, for example: 

./MekHQ.sh

Stuck? Most Mac questions are answered on the macOS issues page.

Linux

Run the program's script from the folder you unpacked, for example: 

./MekHQ.sh

MegaMek.sh and MegaMekLab.sh start the other programs.

Running a dedicated server

Hosting games for your group? MegaMek is also published as a Docker image. It runs a dedicated server on any Linux machine, amd64 or arm64, with Java built in. 

docker run -d --pull always -p 2346:2346 -v ./userdata:/app/userdata ghcr.io/megamek/megamek:latest

latest is the newest Core release. Players must run the same version as the server, so pin a version tag for a long game.
