# MegaMek Launcher privacy policy

## Scope

This policy describes MegaMek Launcher, the desktop application maintained by the
MegaMek project. It does not describe every MegaMek program, website feature, or
external service. Games started by the launcher have their own networking
features.

## Information kept on your computer

The launcher stores installation registrations, local installation paths,
preferences, update-management records, and diagnostic logs on your computer.
It does not automatically upload these records, your saves, or your campaign
files to MegaMek or GitHub.

The launcher does not include analytics or automatic crash-report uploads.
If you choose to share diagnostics with support, review them first: logs can
contain local paths and other technical information.

## Connections made by the launcher

When installed using the official installers, the launcher automatically checks
GitHub on startup for newer launcher releases.

The launcher can also check for game updates on startup when automatic checks
are enabled for a managed installation. Manual release browsing, update checks,
verification of imported installations, and confirmed downloads contact GitHub
and its download infrastructure.

Opening Settings retrieves the MegaMek news feed from
[megamek.org/feed.xml](https://megamek.org/feed.xml).

These connections provide release information, downloads, and project news.
Checking for an update does not authorize its installation. Installing launcher
or game updates requires your confirmation.

## What hosting services receive

GitHub handles release downloads and hosts the news feed through GitHub Pages.
These services receive your IP address and normal request information, such as
the request time, requested resource, and HTTP headers. They may retain access
logs. See the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for their data-handling practices.

## Your choices

Automatic game-update checks can be enabled or disabled for each managed
installation. These settings do not control the launcher's own startup update
check, which has no setting to disable it.
