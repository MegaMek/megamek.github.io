# Code signing policy

This policy covers Windows MSI installers for
[MegaMek Launcher](https://github.com/MegaMek/mm-launcher).

**Signing status:** Windows installer signing is not yet active. Current
releases are unsigned.

## Signing provider

Free code signing provided by
[SignPath.io](https://about.signpath.io), certificate by
[SignPath Foundation](https://signpath.org).

## Team

**Authors, reviewers, and signing approvers:**
[IllianiBird](https://github.com/IllianiBird) and
[HammerGS](https://github.com/HammerGS).
